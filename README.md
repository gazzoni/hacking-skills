# indiehacking plugins

Marketplace dos plugins de apoio à metodologia indie-hacker do Gazzoni.

## Plugins

- **indiehacking-build** — Fase Build (Gate 2). Em desenvolvimento.
- **indiehacking-model** — Fase Modelagem (Gate 1). Futuro.
- **indiehacking-marketing** — Fase Marketing (Gate 2 canal + Gate 3 Graduação). Futuro.

## Instalação

```bash
claude plugin marketplace add gazzoni/indiehacking-plugins
claude plugin install indiehacking-build@indiehacking
```
